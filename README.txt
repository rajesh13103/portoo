HOW TO ADD YOUR CERTIFICATES:
==============================

1. Add your certificate IMAGE files here (JPG or PNG):
   - html-cert.jpg
   - css-cert.jpg
   - js-cert.jpg
   - python-cert.jpg
   - c-cert.jpg
   - hackathon1.jpg
   - participation1.jpg

2. Add your certificate PDF files here for download:
   - html-cert.pdf
   - css-cert.pdf
   - js-cert.pdf
   - python-cert.pdf
   - c-cert.pdf
   - hackathon1.pdf
   - participation1.pdf

3. To add MORE certificates, copy a cert-card block in index.html
   and update the file names, title, and issuer.

4. Categories available: skill | hackathon | participation
